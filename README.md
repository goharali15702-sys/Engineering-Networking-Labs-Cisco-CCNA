# 🌐 Engineering Networking Labs (CCNA)

A collection of hands-on Cisco CCNA networking labs built using **Cisco Packet Tracer**.

This repository documents my journey from networking fundamentals to enterprise-level networking by **designing, configuring, verifying, and troubleshooting** real-world network scenarios.

* Learn real-world network design and implementation.
* Develop configuration and troubleshooting skills.

* Build a professional networking portfolio on GitHub.

## 📖 How to Use

1. Open the desired lab folder.
2. Read the `README.md` to understand the lab objectives and topology.
3. Open the `.pkt` file using **Cisco Packet Tracer**.
4. Follow the configuration steps.
5. Review the configuration files.
6. Run the provided verification commands.
7. Compare your results with the documented expected results.

## 🧠 Learning Approach

Each lab follows a practical networking workflow:

```text
Understand
    ↓
Design
    ↓
Build
    ↓
Configure
    ↓
Verify
    ↓
Troubleshoot
    ↓
Document
    ↓
Publish to GitHub
```

Large CCNA topics are divided into multiple focused labs when they contain several distinct technologies or configuration methods.

For example:

```text
ACL
├── Standard ACL
└── Extended ACL

NAT
├── Static NAT
├── Dynamic NAT
├── PAT with NAT Pool
└── PAT with Interface
```

This approach allows each technology to be practiced and documented independently before combining them into larger network scenarios.
