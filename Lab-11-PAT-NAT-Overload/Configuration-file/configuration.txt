Lab 11 – PAT (NAT Overload)
Configuration

==================================================
Router0 – NAT Router
==================================================

enable
configure terminal

interface GigabitEthernet0/0
 ip address 192.168.10.1 255.255.255.0
 ip nat inside
 no shutdown
exit

interface GigabitEthernet0/1
 ip address 172.165.20.1 255.255.0.0
 ip nat outside
 no shutdown
exit

access-list 2 permit 192.168.10.0 0.0.0.255

ip nat inside source list 2 interface GigabitEthernet0/1 overload

ip route 192.168.20.0 255.255.255.0 172.165.20.2

end

==================================================
Router1 – ISP Router
==================================================

enable
configure terminal

interface GigabitEthernet0/0
 ip address 172.165.20.2 255.255.0.0
 no shutdown
exit

interface GigabitEthernet0/1
 ip address 192.168.20.1 255.255.255.0
 no shutdown
exit

ip route 192.168.10.0 255.255.255.0 172.165.20.1

end

The Lab 10 Dynamic NAT pool was removed:

ip nat inside source list 2 interface GigabitEthernet0/1 overload
